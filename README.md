# Smollink Frontend

> A clean, minimal, and user-friendly interface for the Smollink URL shortener app.

**Status:** 🚧 In Development - Phase 1

This is the frontend application for Smollink, designed to provide an intuitive interface for creating short links, customizing metadata, and viewing analytics.

## Planned Features

- **Shorten URLs** – Quick and simple link creation with custom slugs.
- **Custom Metadata** – Add title, description, and preview image for social sharing.
- **User Dashboard** – Signed-in users will be able to:
  - View their links and analytics
  - See clicks over time (daily, weekly, monthly)
  - Monitor geography, devices, and referrer sources
- **Dynamic Link Options** – Manage link expiration and redirects (by device or region).
- **Responsive UI** – Works well on desktop, tablet, and mobile devices.

This project is currently in its initial phase. The repository structure and core features are being planned and will be implemented soon.
